# FPGA Clustering Pipeline 调参工具使用说明

## 概述

本tuner基于BOHB (Bayesian Optimization and Hyperband) 算法，用于自动优化 `fpga_clustering_pipline_gift` 项目的参数。

## 一、安装依赖

```bash
cd /export/home/keli/ZPJ_FCCM/fpga_clustering_pipline_gift
pip install -r tuner/requirements.txt
```

安装后验证：
```bash
python tuner/test_tuner_setup.py
```

## 二、配置调参

### 2.1 设置基本路径

编辑 `tuner/run_tuner.sh`：

```bash
# 1. 设置benchmark路径
BENCHMARK_DIR="/work/fpga_clustering_pipline_gift/data/ispd2016/FPGA03"

# 2. 设置DREAMPlace路径
DREAMPLACE_PATH="/work/fpga_clustering_pipline_gift/tools/DREAMPlaceFPGA"

# 3. 设置优化参数
N_ITERATIONS=50        # 调参迭代次数（越多越好，但时间更长）
N_WORKERS=4           # 并行运行的worker数量
```

### 2.2 设置基线PPA

编辑 `tuner/tuner_configs.py`，更新你的benchmark的基线结果：

```python
CLUSTERING_BASE_PPA = {
    "FPGA03": {
        "hpwl": 3e6,      # 更新为实际的HPWL基线
        "runtime": 1000,   # 更新为实际的运行时间（秒）
        "overflow": 0.15,  # 更新为实际的overflow
    },
}
```

**如何获取基线PPA：**
```bash
# 先用默认参数运行一次
python run_complete_flow_with_json.py --params_json run_complete_flow_params_template.json

# 查看输出日志，记录HPWL、runtime、overflow作为基线
```

### 2.3 调整优化目标

在 `run_tuner.sh` 中设置优化目标的权重：

```bash
# 单目标优化（默认）
MULTIOBJ=false
HPWL_RATIO=1.0        # HPWL的权重
RUNTIME_RATIO=0.3     # 运行时间的权重
OVERFLOW_RATIO=0.5    # Overflow的权重

# 多目标优化（生成Pareto前沿）
MULTIOBJ=true
NUM_PARETO=5          # 提议的Pareto最优点数量
```

### 方式3：手动运行

```bash
cd /export/home/keli/ZPJ_FCCM/fpga_clustering_pipline_gift

# 启动master进程
python tuner/tuner_train.py \
    --n_iterations 50 \
    --n_workers 4 \
    --log_dir ./logs_tuner \
    --run_id tuning_run \
    --run_args \
        benchmark_dir=/work/.../FPGA03 \
        dreamplace_path=/work/.../DREAMPlaceFPGA \
        base_ppa=FPGA03 \
        gpu=0 \
    &

# 等待3秒让master启动
sleep 3

# 启动worker进程（启动4个）
for i in 0 1 2 3; do
    python tuner/tuner_train.py \
        --worker \
        --worker_id $i \
        --log_dir ./logs_tuner \
        --run_id tuning_run \
        --run_args \
            benchmark_dir=/work/.../FPGA03 \
            dreamplace_path=/work/.../DREAMPlaceFPGA \
            base_ppa=FPGA03 \
            gpu=0 \
        &
done
```

## 五、优化的参数说明

### 5.1 Clustering参数
- `min_cluster_size` (30-100): Louvain最小cluster大小
  - 较小：产生更多小clusters，细粒度控制
  - 较大：产生较少大clusters，粗粒度控制

- `resolution` (0.5-2.0): Louvain分辨率
  - 较小：较少的大clusters
  - 较大：较多的小clusters

- `gift_scale` (0.3-0.8): GIFT布局初始化范围
  - 较小：初始布局更紧凑
  - 较大：初始布局更分散

### 5.2 Cluster Placement参数
- `utilization` (0.8-1.5): Cluster节点大小利用率
  - 较小：cluster节点更大，留更多空间
  - 较大：cluster节点更小，更紧凑

- `sigma_ratio` (0.7-1.0): 单元在cluster内的散布程度
  - 较小：单元更集中在cluster中心
  - 较大：单元更分散

- `cluster_base_weight` (0.1-5.0): Cluster网络基础权重
- `cluster_fixed_cluster_weight` (5.0-100.0): 固定节点与cluster之间网络的增强权重

### 5.3 Net Reweighting参数
- `intra_sub` (1.0-2.0): 同一sub-cluster内网络权重
- `intra` (0.8-1.5): 同一cluster内跨sub-cluster网络权重
- `inter` (0.5-1.2): 跨cluster网络权重

### 5.4 Final Placement参数
- `learning_rate` (0.001-0.05): 梯度下降学习率

## 六、常见问题

### Q1: Pyro4相关错误
```
ModuleNotFoundError: No module named 'Pyro4'
```
**解决：** 安装依赖
```bash
pip install -r tuner/requirements.txt
```

### Q2: Worker超时
**解决：** 增加超时时间，编辑 `tuner/tuner_worker.py`：
```python
result = subprocess.run(cmd, timeout=10800)  # 3小时
```

### Q3: GPU内存不足
**解决：** 减少并行worker数量：
```bash
N_WORKERS=2  # 在 run_tuner.sh 中修改
```

### Q4: 找不到benchmark
**解决：** 检查路径设置，确保 `BENCHMARK_DIR` 正确

### Q5: 结果不收敛
**解决：** 
- 增加迭代次数 `N_ITERATIONS`
- 检查基线PPA是否合理
- 调整参数搜索范围

## 七、高级用法

### 7.1 自定义搜索空间

编辑 `tuner/configspace.json`：

```json
{
  "hyperparameters": [
    {
      "name": "min_cluster_size",
      "type": "uniform_int",
      "lower": 40,        // 修改下界
      "upper": 80,        // 修改上界
      "default": 50
    }
  ]
}
```

### 7.2 多目标优化

在 `run_tuner.sh` 中设置：
```bash
MULTIOBJ=true

display logs_tuner_*/best_cfgs/*.pareto.png

# 在 run_tuner.sh 中设置

```

## 八、性能建议

### 8.1 资源配置建议

| 场景 | N_ITERATIONS | N_WORKERS | 预计时间 |
|------|--------------|-----------|----------|
| 快速测试 | 5 | 2 | 1-2小时 |
| 中等调优 | 50 | 4 | 1天 |
| 深度调优 | 200 | 8 | 3-5天 |

### 8.2 优化策略

1. **先粗后细**：先用少量迭代找到大致方向，再增加迭代精细调优
2. **分阶段优化**：先优化clustering参数，再优化placement参数
3. **使用多目标**：如果不确定权重，使用多目标优化获得Pareto前沿
